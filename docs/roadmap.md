# PhotoCatalog 路线图：Lightroom 平替

目标：在本地、零外部依赖的前提下，覆盖 Lightroom Classic 的三件核心事：**图库管理与选片**（Library）、**非破坏式 RAW 调整**（Develop）、**渲染导出与交付**（Export）。每项功能独立提交，均需通过 `--selfcheck` / `--pipeline` 并在真实规模目录库上验证。

## 已完成（基础）

- 原生三栏界面（侧边栏 / 内容 / 简介）、统一工具栏、跟随系统的深色模式
- 性能：评分 341 → 50 ms，选中、筛选、排序提速 26–43%；RAW 缩略图修复不再阻塞界面
- RAW+JPEG 同名配对显示为一张照片，编辑同时作用于两个文件

## 第一阶段：选片（Library 核心）

- [x] RAW+JPEG 配对显示为一张
- [x] 单张 / 比较视图 1:1 缩放、平移，比较视图联动（`Z` 或双击）
- [x] 撤销 / 重做（⌘Z / ⇧⌘Z）：评分、旗标、颜色、关键词、文本、拍摄时间、从目录库移除
- [x] 选片节奏：评分 / 旗标后自动前进（Shift 单次），Tab 隐藏侧边面板，一次性移除当前视图中被拒绝的照片
- [x] 与其他应用协作：右键菜单（打开 / 打开方式 / 在访达中显示 / 分享 / 评分 / 旗标 / 颜色 / 移除）、拖出照片、拖入文件夹导入

## 第二阶段：修图（Develop）

- [x] 非破坏式基本调整（CIRAWFilter）：曝光、对比度、高光、阴影、白色、黑色、色温、色调、鲜艳度、饱和度；拖动实时预览（RAW 解码缓存，每次渲染约 7 ms）、修改前 / 后、可撤销
- [x] 裁剪（比例预设、拖动角 / 边 / 整体）、拉直（角度滑块、画线拉直、按地平线自动拉直）、90° 旋转与水平翻转
- [x] RGB 直方图（随拖动实时更新，高光 / 阴影剪切提示）与修改前 / 后对比（`\`）
- [x] 拷贝 / 粘贴 / 同步调整（逐项勾选），内置与自定义预设
- [x] 网格缩略图、胶片栏、单张 / 比较预览和 1:1 视图都反映调整；已修图照片带标记

## 第三阶段：导出与交付

- [x] 渲染导出：尺寸、格式（JPEG / HEIC / TIFF）、质量、色彩空间、命名模板、水印、元数据与 GPS 去除
- [x] 导出预设与批量导出队列

## 第四阶段：导入与元数据

- [x] 存储卡导入：自动识别存储卡（含 DCIM 的卷），按天勾选、标出已导入的照片，复制到按日期整理的文件夹，导入时重命名（RAW+JPEG 同名同号），同时备份到第二位置，完成后推出
- [x] 相机 / iPhone 直连导入（ImageCaptureCore，PTP 设备）：连接后出现在侧边栏“设备”与存储卡导入窗口，按天挑选、标出已导入，边下载边按存储卡规则整理、重命名、备份；下载先暂存在目标磁盘上，放好即删（已用模拟设备测试，尚待真机验证）
- [x] 元数据模板（作者 / 版权，导入时自动应用，`{year}` 取拍摄年份）
- [x] 关键词管理：重命名、合并、删除（侧边栏关键词右键，下级关键词一并处理，可撤销）
- [x] 位置：GPX 轨迹匹配（相机时区对齐、插值）、在地图上搜索或点按设置位置、移除位置；位置写入 XMP
- [x] 人物：本机 Vision 人脸检测与分组、命名前勾选检查、同名合并、不是此人、自动建议需确认；确认的人物写入“人物/名字”关键词（分组基于外观特征，不是身份识别，长相相近的人可能被分到一组）

## 第五阶段：修图补全与选片提速

- [x] 细节：锐化（数量、半径、边缘蒙版）、明亮度 / 颜色降噪；在相机默认处理之上叠加，预览按缩放比例换算半径
- [x] 手动镜头校正：扭曲度、镜头暗角与中点（Apple 的 RAW 引擎没有 Canon RF 镜头的配置文件，未校正的 RAW 广角端畸变与暗角明显）
- [x] 效果：裁剪后暗角（数量、中点、羽化，随裁剪框）、颗粒（数量、大小、粗糙度）
- [x] 白平衡吸管（`W`，点选中性灰）、自动色调（`⌘U`，修图中的照片或网格中的全部所选照片）
- [x] 快捷收藏（`B`，资料库中列出、存入目录库、可撤销，网格缩略图带标记）
- [x] 筛选视图（`N`，所选照片尽可能大地并排，方向键切换当前照片，评分 / 旗标只作用于当前照片，悬停 × 移出，返回网格时保留剩下的选择）
- [x] 纹理、清晰度（中间调局部对比，负值柔化）、去朦胧（暗通道先验，负值加雾）
- [x] 色调曲线（点曲线，RGB 复合与单通道，单调三次样条，预设）
- [x] HSL / 混色器（8 个色带的色相、饱和度、明亮度，按色度加权，白色与灰色不受影响）
- [x] 颜色分级（阴影、中间调、高光与全局的色调和明亮度，混合与平衡控制区域交界）
- [x] 局部调整：线性 / 径向渐变（`M` / `⇧M` 拖动绘制，控制点移动、旋转、调整形状，反相，各自的曝光、对比、高光、阴影、白色、黑色、色温、色调、纹理、清晰度、去朦胧、饱和度；蒙版记在原片坐标上，裁剪、旋转后仍贴在同一处）
- [x] 局部调整：画笔（`K`，大小、羽化、密度，按住 `⌥` 擦除，`[` / `]` 调整大小；`O` 用红色叠加显示所选蒙版的范围；“用画笔增减”在渐变、主体、天空蒙版上涂抹扩大或擦除）
- [x] 局部调整：自动选择主体（Vision 前景分割）与天空（从上边缘生长的平滑明亮 / 蓝色区域，在地平线与主体处停止；Vision 场景分类确认），按原片 1024 像素计算，预览、缩略图与导出一致
- [x] 污点去除（`Q`，点按修复并自动寻找周围匹配的取样处，向外拖动设定大小；修复匹配周围的颜色与亮度，仿制原样复制；拖动污点或取样圆移动、拖动边缘调整大小；“显示污点”只显示细节以找出传感器灰尘）
- [x] 修图快照与步骤历史（每张照片的每一步调整存入目录库，点按回到某一步或某个快照；撤销去掉一步，重做放回；快照可新建、重命名、用当前设置更新、删除）
- [x] 虚拟副本（`⌘'`，同一原件的另一条目录记录，修图与元数据各自独立；不算重复、不参与 RAW+JPEG 配对、不写共享的 XMP；原件改名、移动、重新定位时副本随之更新；移除副本只从目录库移除，移除原照时副本一并移除）
- [x] 批量重命名原件（「照片」菜单或右键「重命名照片…」：命名模板与占位符、起始序号，改名前预览新文件名，RAW+JPEG 一起改名，虚拟副本随之更新）
- [x] 相册集（可嵌套，收纳相册、智能相册与其他相册集；右键「移到相册集」，删除相册集时其中内容移到上一层）
- [x] 在外部编辑器中编辑（`⌥⌘E`，连同修图调整存为原件旁的 16 位 TIFF 副本「…-编辑.tif」，带原片的评分、标签、关键词加入目录库并与原片叠放，再用选定的应用打开；原件不动，编辑器保存后经文件夹监视刷新）
- [x] 读取外部修改的 XMP（其他应用改动 .xmp 后标出照片并列入「管理 → 元数据已在外部更改」，「从文件读取元数据」可撤销且不回写；可选自动读取；本应用自己写入的不算改动）

## 第六阶段：预设与修图工具

- [x] 导入时应用修图预设（设置 → 导入、导入窗口与存储卡导入窗口中选择；新照片套用预设并记入修图历史）
- [ ] 预设悬停预览
- [ ] 预设强度（0–200%）
- [ ] 预设管理：重命名、用当前设置更新、分组
- [ ] 预设导入 / 导出（含读取 Lightroom `.xmp` 预设）
- [ ] 按相机设定 RAW 默认设置
- [ ] 透视校正（垂直 / 水平 / 自动）
- [ ] 修改前后左右并排对比
- [ ] 颜色范围 / 明亮度范围蒙版
- [ ] LUT（`.cube`）

## 发布准备

- [x] 50 万张规模：元数据以紧凑形式常驻内存（50 万张约 1 GB，未改用分页查询）；启动 1 秒内显示首屏、约 5 秒完整可用，筛选 / 排序 / 搜索 / 切换收藏 0.1–0.35 秒，评分约 50 毫秒（`--scale` 基准与真实界面实测）
- [x] 崩溃报告：意外退出后，下次启动提示并可在访达中显示 macOS 保存的崩溃报告（只在本机）
- [x] 检查更新：“检查更新…”对比 GitHub 最新发布版本并打开下载页（仅在选择时联网）
- [ ] 签名与公证：`script/release.sh` 已就绪（强化运行时、公证、装订），需要 Developer ID 证书
- [ ] 自动安装更新：需在签名之后实现
- [x] 多语言：简体中文与英文界面，跟随系统或在设置中切换（其他系统语言使用英文）；`script/check_localization.py` 检查未翻译的文字
