# PhotoCatalog 路线图：Lightroom 平替

目标：在本地、零外部依赖的前提下，覆盖 Lightroom Classic 的三件核心事：**图库管理与选片**（Library）、**非破坏式 RAW 调整**（Develop）、**渲染导出与交付**（Export）。每项功能独立提交，均需通过 `--selfcheck` / `--pipeline` 并在真实规模目录库上验证。

## 已完成（基础）

- 原生三栏界面（侧边栏 / 内容 / 简介）、统一工具栏、跟随系统的深色模式
- 性能：评分 341 → 50 ms，选中、筛选、排序提速 26–43%；RAW 缩略图修复不再阻塞界面
- RAW+JPEG 同名配对显示为一张照片，编辑同时作用于两个文件

## 第一阶段：选片（Library 核心）

- [x] RAW+JPEG 配对显示为一张
- [x] 单张 / 比较视图 1:1 缩放、平移，比较视图联动（`Z` 或双击）
- [x] 撤销 / 重做（⌘Z / ⇧⌘Z）：评分、旗标、颜色、关键词、文本、拍摄时间、从目录库移除
- [x] 选片节奏：评分 / 旗标后自动前进（Shift 单次），Tab 隐藏侧边面板，一次性移除当前视图中被拒绝的照片
- [x] 与其他应用协作：右键菜单（打开 / 打开方式 / 在访达中显示 / 分享 / 评分 / 旗标 / 颜色 / 移除）、拖出照片、拖入文件夹导入

## 第二阶段：修图（Develop）

- [x] 非破坏式基本调整（CIRAWFilter）：曝光、对比度、高光、阴影、白色、黑色、色温、色调、鲜艳度、饱和度；拖动实时预览（RAW 解码缓存，每次渲染约 7 ms）、修改前 / 后、可撤销
- [x] 裁剪（比例预设、拖动角 / 边 / 整体）、拉直（角度滑块、画线拉直、按地平线自动拉直）、90° 旋转与水平翻转
- [x] RGB 直方图（随拖动实时更新，高光 / 阴影剪切提示）与修改前 / 后对比（`\`）
- [x] 拷贝 / 粘贴 / 同步调整（逐项勾选），内置与自定义预设
- [x] 网格缩略图、胶片栏、单张 / 比较预览和 1:1 视图都反映调整；已修图照片带标记

## 第三阶段：导出与交付

- [x] 渲染导出：尺寸、格式（JPEG / HEIC / TIFF）、质量、色彩空间、命名模板、水印、元数据与 GPS 去除
- [x] 导出预设与批量导出队列

## 第四阶段：导入与元数据

- [x] 存储卡导入：自动识别存储卡（含 DCIM 的卷），按天勾选、标出已导入的照片，复制到按日期整理的文件夹，导入时重命名（RAW+JPEG 同名同号），同时备份到第二位置，完成后推出
- [x] 相机 / iPhone 直连导入（ImageCaptureCore，PTP 设备）：连接后出现在侧边栏“设备”与存储卡导入窗口，按天挑选、标出已导入，边下载边按存储卡规则整理、重命名、备份；下载先暂存在目标磁盘上，放好即删（已用模拟设备测试，尚待真机验证）
- [x] 元数据模板（作者 / 版权，导入时自动应用，`{year}` 取拍摄年份）
- [x] 关键词管理：重命名、合并、删除（侧边栏关键词右键，下级关键词一并处理，可撤销）
- [x] 位置：GPX 轨迹匹配（相机时区对齐、插值）、在地图上搜索或点按设置位置、移除位置；位置写入 XMP
- [x] 人物：本机 Vision 人脸检测与分组、命名前勾选检查、同名合并、不是此人、自动建议需确认；确认的人物写入“人物/名字”关键词（分组基于外观特征，不是身份识别，长相相近的人可能被分到一组）

## 第五阶段：修图补全与选片提速

- [x] 细节：锐化（数量、半径、边缘蒙版）、明亮度 / 颜色降噪；在相机默认处理之上叠加，预览按缩放比例换算半径
- [x] 手动镜头校正：扭曲度、镜头暗角与中点（Apple 的 RAW 引擎没有 Canon RF 镜头的配置文件，未校正的 RAW 广角端畸变与暗角明显）
- [x] 效果：裁剪后暗角（数量、中点、羽化，随裁剪框）、颗粒（数量、大小、粗糙度）
- [x] 白平衡吸管（`W`，点选中性灰）、自动色调（`⌘U`，修图中的照片或网格中的全部所选照片）
- [x] 快捷收藏（`B`，资料库中列出、存入目录库、可撤销，网格缩略图带标记）
- [x] 筛选视图（`N`，所选照片尽可能大地并排，方向键切换当前照片，评分 / 旗标只作用于当前照片，悬停 × 移出，返回网格时保留剩下的选择）
- [x] 纹理、清晰度（中间调局部对比，负值柔化）、去朦胧（暗通道先验，负值加雾）
- [x] 色调曲线（点曲线，RGB 复合与单通道，单调三次样条，预设）
- [x] HSL / 混色器（8 个色带的色相、饱和度、明亮度，按色度加权，白色与灰色不受影响）
- [x] 颜色分级（阴影、中间调、高光与全局的色调和明亮度，混合与平衡控制区域交界）
- [x] 局部调整：线性 / 径向渐变（`M` / `⇧M` 拖动绘制，控制点移动、旋转、调整形状，反相，各自的曝光、对比、高光、阴影、白色、黑色、色温、色调、纹理、清晰度、去朦胧、饱和度；蒙版记在原片坐标上，裁剪、旋转后仍贴在同一处）
- [x] 局部调整：画笔（`K`，大小、羽化、密度，按住 `⌥` 擦除，`[` / `]` 调整大小；`O` 用红色叠加显示所选蒙版的范围；“用画笔增减”在渐变、主体、天空蒙版上涂抹扩大或擦除）
- [x] 局部调整：自动选择主体（Vision 前景分割）与天空（从上边缘生长的平滑明亮 / 蓝色区域，在地平线与主体处停止；Vision 场景分类确认），按原片 1024 像素计算，预览、缩略图与导出一致
- [x] 污点去除（`Q`，点按修复并自动寻找周围匹配的取样处，向外拖动设定大小；修复匹配周围的颜色与亮度，仿制原样复制；拖动污点或取样圆移动、拖动边缘调整大小；“显示污点”只显示细节以找出传感器灰尘）
- [x] 修图快照与步骤历史（每张照片的每一步调整存入目录库，点按回到某一步或某个快照；撤销去掉一步，重做放回；快照可新建、重命名、用当前设置更新、删除）
- [x] 虚拟副本（`⌘'`，同一原件的另一条目录记录，修图与元数据各自独立；不算重复、不参与 RAW+JPEG 配对、不写共享的 XMP；原件改名、移动、重新定位时副本随之更新；移除副本只从目录库移除，移除原照时副本一并移除）
- [x] 批量重命名原件（「照片」菜单或右键「重命名照片…」：命名模板与占位符、起始序号，改名前预览新文件名，RAW+JPEG 一起改名，虚拟副本随之更新）
- [x] 相册集（可嵌套，收纳相册、智能相册与其他相册集；右键「移到相册集」，删除相册集时其中内容移到上一层）
- [x] 在外部编辑器中编辑（`⌥⌘E`，连同修图调整存为原件旁的 16 位 TIFF 副本「…-编辑.tif」，带原片的评分、标签、关键词加入目录库并与原片叠放，再用选定的应用打开；原件不动，编辑器保存后经文件夹监视刷新）
- [x] 读取外部修改的 XMP（其他应用改动 .xmp 后标出照片并列入「管理 → 元数据已在外部更改」，「从文件读取元数据」可撤销且不回写；可选自动读取；本应用自己写入的不算改动）

## 第六阶段：预设与修图工具

- [x] 导入时应用修图预设（设置 → 导入、导入窗口与存储卡导入窗口中选择；新照片套用预设并记入修图历史）
- [x] 预设悬停预览（修图面板「预设」区块按组列出，鼠标停在预设上即在照片上预览，点按应用）
- [x] 预设强度（在修图中应用预设后出现强度滑块，0–200%；滑块、白平衡、曲线、混色器、颜色分级与蒙版自身的调整按比例缩放，其他调整后消失）
- [x] 预设管理：右键重命名、用当前设置更新、移到组 / 新建组、删除（先确认）；新建预设时可选组
- [x] 预设导入 / 导出（.xmp：本应用导出的文件完整往返，含蒙版与污点；同时写入 Camera Raw 属性供 Lightroom 导入；读取 Lightroom / Camera Raw 预设中两者共有的设置，并说明未导入的部分）
- [x] 按相机设定 RAW 默认设置（设置 → 修图：所有相机与各相机各选一个预设，或保持原照；导入时先套用，导入预设叠加其上；复位回到默认设置；预设右键可设为当前相机的默认）
- [x] 透视校正（修图面板「变换」：垂直、水平滑块；自动 / 垂直 Upright 从照片中的直线段找出竖线与立面横线的消失点；裁剪自动避开空白角，蒙版与污点随之换算）
- [x] 修改前后并排对比（`Y`：修改前沿用修改后的裁剪、旋转与透视，只比较色调与颜色；左右或上下，取照片显示更大的一种；修改后随拖动实时更新）
- [x] 颜色范围 / 明亮度范围蒙版（独立的范围蒙版，或把任何蒙版限定在一定明暗或颜色范围内；颜色在照片上点按取样最多 5 处，按蒙版之前的照片判断，随全局调整变化）
- [x] LUT（导入 `.cube` 3D LUT 到所有目录库共用的 LUT 库，照片可选一个并设强度；在曲线、混色器与颜色分级之后以 sRGB 应用；非 2 的幂尺寸自动重采样）

## 第七阶段：照片合并

- [x] HDR 合并（照片 → 照片合并 → HDR…，⌃H：2–9 张不同曝光的照片，中值阈值位图自动对齐，曝光融合（Mertens，拉普拉斯金字塔），可选消除重影；预览；结果存为中间曝光照片旁的 16 位 TIFF「…-HDR.tif」，带原片元数据加入目录库）
- [x] 全景合并（照片 → 照片合并 → 全景…，⌃M：2–30 张相互重叠的照片按顺序投影到柱面（焦距取自 EXIF），掩码归一化互相关对齐，自动判断横向或竖向，重叠区曝光补偿与羽化融合，自动裁剪到最大的完整矩形；重叠不足时指明是哪两张；结果存为第一张照片旁的「…-Pano.tif」）

## 第八阶段：修图补充

- [x] 自动白平衡（白平衡面板的「自动」或 照片 → 自动白平衡，⇧⌘U：在相机记录的白平衡下，从中性附近找到最近的色彩群集作为灰色表面，亮的像素权重更高，再求解色温与色调让它们呈中性；结果与滑块起点无关；画面中没有接近灰色的内容时不做判断；修图中的照片或网格中的全部所选照片）
- [x] 色差校正与去边（镜头校正中的「删除色差」：在照片的消色差边缘上测量横向色差——红、蓝相对绿色的放大率差异，每个文件测一次——再把红、蓝缩放回原位；「紫边去除 / 绿边去除」0–20，去掉高反差边缘旁紫色、绿色镶边的颜色；预设文件对应 Camera Raw 的 AutoLateralCA 与 Defringe 数量）
- [x] 人像蒙版（蒙版中的「选择人物」：整个人物、面部皮肤、身体皮肤、眉毛、眼白、虹膜和瞳孔、嘴唇、牙齿；来自 Vision 的人物分割、人物实例与面部特征点，皮肤按脸部自身的肤色判断；多人时可选所有人或其中一人（从左到右编号），之后还能改选部位）

## 第九阶段：AI 增强（本机 Core ML 模型）

- [x] AI 降噪（照片 → 增强…，⌃⌥I：SCUNet 真实噪声模型，强度 0–100；在 GPU 上逐块处理，2400 万像素约 50 秒）
- [x] 超分辨率（同一对话框：Real-ESRGAN 通用模型的弱降噪版，宽高各 2 倍；可与降噪一起做；结果存为原片旁的 16 位 TIFF「…-Enhanced.tif」，带原片元数据与修图设置（白平衡除外）加入目录库；对话框中有 100% 前后对比预览）
- [x] 智能移除（污点去除工具的「移除」模式：在照片上涂抹物体，松开后由 LaMa 按周围内容补全；补全在原片全尺寸上生成一次，存入缓存，之后按修复的方式匹配当前的颜色与亮度，改曝光或白平衡后依然衔接；可撤销，可调不透明度）

## 第十阶段：AI 助手（大语言模型）

- [x] 服务设置（设置 → AI：Anthropic Claude 或任何兼容 OpenAI 的接口——OpenAI、DeepSeek、通义千问、豆包、Kimi、智谱、本机的 Ollama / LM Studio；服务地址、模型、能否识别图片、测试连接；API Key 存在钥匙串；只在使用功能时联网，照片只发 1024 像素预览）
- [x] AI 描述照片（照片 → AI 描述照片…，⌃⌥D：看 1024 像素预览，写关键词、标题、说明；关键词追加，标题和说明只填空白，可选替换；一次最多 3 张并行，状态栏显示进度可取消；一次撤销全部）
- [x] 用自然语言查找照片（视图 → 用自然语言查找…，⌥⌘F：一句话换成筛选栏条件和搜索词——评分、旗标、颜色、类型、相机、镜头、拍摄日期、位置；只发送这句话和相机、镜头、关键词名称）
- [x] 用文字描述想要的效果来修图（修图面板「AI 调整」：描述换成基本、偏好、效果、白平衡与颜色分级的新数值，限制在滑块范围内，一步撤销，并显示模型的简短说明）

## 第十一阶段：修图基调、交付与图库补全

按日常使用频率排序，逐项完成后合并到 main。

- [x] 配置文件（修图面板「配置文件」：标准即相机引擎的原始渲染；中性、鲜艳、人像、风景是本应用自己的基础影调与颜色响应——一条色调曲线、各色带的响应与整体饱和度——作用在所有调整之前，数量 0–200%；悬停预览；可拷贝、同步、存入预设，预设强度按比例缩放；读取 Lightroom 预设时 Adobe / 相机配置文件对应到最接近的一种。单色随下一项的黑白模式提供）
- [x] 黑白模式与黑白混合（配置文件中的处理方式「彩色 / 黑白」或「单色」配置文件；黑白时混色器换成 8 个色带的黑白混合，按像素的鲜艳程度起作用，灰色不变；「自动」按照片主要颜色的明暗把它们在黑白中拉开，不压暗肤色所在的橙色；颜色分级可为黑白照片上色调（如棕褐色）；内置的「黑白」预设改用单色；与 Camera Raw 的 ConvertToGrayscale、GrayMixer 互通）
- [x] 校准（修图面板底部「校准」：阴影色调（绿 ↔ 洋红，只作用于暗部，黑色不变）；红、绿、蓝原色的色相与饱和度，用线性光上保持白色与灰色不变的矩阵实现；最先应用，在配置文件之前；与 Camera Raw 的 ShadowTint、RedHue…BlueSaturation 互通）
- [x] 导出锐化（导出窗口「输出锐化」：屏幕、亚光纸、光面纸，低 / 标准 / 高；在缩放到输出尺寸之后只锐化明亮度，纸张用更大的半径；内置的网络分享与社交媒体预设默认为屏幕锐化）
- [x] 软打样（修图中按 S 或面板顶部「软打样」：经 sRGB、Display P3、Adobe RGB 或本机安装的打印机配置文件预览照片，可感知 / 相对比色（经 ColorSync 按所选方法转换），可模拟纸张与墨水；「色域警告」以红色标出色相、饱和度或亮度无法保留的颜色，只是打印成墨水黑的暗部不算；直方图显示校样）
- [x] 打印（⌘P：纸张尺寸与方向、边距；每页一张（适合或填满裁切）或联系表（行 × 列、间距）；旋转以适合；文件名或标题标注；按纸上尺寸以 150–360 ppi 渲染（不解码多于所需），亚光 / 光面纸打印锐化，由打印机管理颜色或经 ColorSync 转换到本机打印机配置文件；窗口中的逐页预览、系统打印与「存储为 PDF」用同一套绘制）
- [ ] 按拍摄时间自动叠放（连拍、包围曝光按时间间隔成组）
- [ ] 视频：导入、缩略图、预览播放，与照片一起评分、加关键词、整理
- [ ] 镜头模糊（按深度模糊背景，可调模糊程度与对焦范围）
- [ ] 更多 AI 蒙版（选择物体；景观：水面、植被、山体、建筑等）
- [ ] 联机拍摄
- [ ] 幻灯片
- [ ] 画册 / 网页（优先级最低）

## 发布准备
