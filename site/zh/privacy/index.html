隐私政策

生效日期：2026 年 10 月 9 日

PhotoCatalog（以下简称“本应用”）由 euynus 开发，GitHub 版与 Mac App Store 版均适用本政策。本应用不收集、不保存、也不出售任何个人数据：没有账户，没有分析统计，没有广告，也不追踪你。

保存在你 Mac 上的数据

目录库（照片的元数据、评分、关键词、修图设置和人脸识别数据）、预览与缓存都只保存在你的 Mac 上，位置由你选择或在本应用自己的文件夹中。备份保存在你选择的位置。人脸识别、AI 蒙版、降噪、超分辨率和 AI 移除都由 App 内置的模型在本机完成。开发者无法访问这些数据。

本应用何时联网

本应用只在以下情况联网：

  • AI 助手（可选）。只有当你在“设置 → AI”中配置了服务、并使用相关功能时才会发送数据，而且直接发往你配置的服务商，开发者不会收到：
    • “AI 描述照片”：缩小到 1024 像素的 JPEG 预览，以及你为该批次勾选附带的拍摄日期、相机、位置和已有关键词。发送前会让你确认。
    • “用自然语言查找”：你输入的句子，以及目录库中的相机、镜头和关键词名称。
    • “AI 调整”：你的描述、照片当前的修图数值；如果所选模型能识别图片，还包括一张缩小的预览。第一次把照片发往本机以外的服务前会先征得你同意。
    这些数据由该服务商依据其隐私政策处理。使用本机服务（如 Ollama、LM Studio）时，数据不会离开你的 Mac。API 密钥保存在 macOS 钥匙串中。
  • 地图。“地点”视图和位置选择器通过 Apple 的 MapKit 加载地图、搜索地点，相关请求由 Apple 依据其隐私政策处理。
  • 检查更新（仅 GitHub 版）。启动后每天最多一次（可在“设置 → 常规”中关闭），或在你选择“检查更新…”时，向 GitHub 的公开接口查询最新版本；更新文件也从 GitHub 下载。请求中不包含你的照片或目录库信息，由 GitHub 依据其隐私声明处理。Mac App Store 版不检查更新，由 App Store 负责。

崩溃报告

本应用崩溃时，macOS 会把报告保存在你的 Mac 上。GitHub 版只会在下次启动时提出帮你在访达中找到它，不会上传。如果你在 macOS 中选择与开发者共享分析数据，Apple 可能依据其政策向开发者提供 Mac App Store 版的崩溃报告。

本网站

本网站（photocatalog.gooday.dev）由 Cloudflare 托管，并使用 Cloudflare Web Analytics 统计访问量。它不使用 Cookie，也不识别或跟踪单个访客：Cloudflare 收到的是每次访问的页面地址、来源网页、浏览器类型和所在国家或地区，只用于汇总统计。这些只涉及本网站，本应用不包含任何统计功能。

政策变更与联系方式

本政策如有变更，会更新在本页并修改生效日期。如有问题，请在 GitHub 上提交 issue。
